الأحكام الأساسية للمدقق

Accepted / مقبول — الدليل كافٍ.
Partially Accepted / مقبول جزئيًا — يوجد امتثال جزئي.
Rejected / مرفوض — الدليل غير كافٍ أو لا يثبت الامتثال.
Needs More Information / يحتاج معلومات إضافية — يفتح مسار RFI.

والقاعدة الأمنية الأساسية: المدقق لا يرى أي شركة إلا إذا تم تعيينه لها فعليًا، ولا يصدر الذكاء الاصطناعي الحكم النهائي؛ القرار البشري للمدقق هو المرجع في مسار المراجعة.

رحلة إدارة منصة 1SaudiCyber / Get Solution أوسع من رحلة الشركة والمدقق؛ لأنها تدير التشغيل التجاري والرقابي للمنصة كلها.

الرحلة الرئيسية للإدارة

تسجيل دخول الإدارة
→ لوحة Platform Admin
→ متابعة حالة المنصة
→ إدارة الشركات والعملاء
→ إدارة الاشتراكات والمدفوعات
→ مراجعة نطاقات الامتثال
→ متابعة تقدم الشركات
→ إدارة المدققين
→ تعيين المدققين للشركات
→ متابعة عمليات المراجعة وطلبات RFI
→ متابعة التقارير والجاهزية
→ إدارة CRM والدعم والمراقبة.

السيناريو المتسلسل

1. لوحة الإدارة الرئيسية: ترى عدد الشركات، الاشتراكات النشطة، المدفوعات المعلقة، طلبات المدققين، التعيينات، تقدم الامتثال، الأدلة، المخاطر، والتنبيهات التي تحتاج إجراء.

2. إدارة الشركات: فتح قائمة الشركات → اختيار شركة → مشاهدة ملفها الكامل → الاشتراك والدفع → الأطر → الضوابط → الأدلة → الفجوات → المخاطر → حالة مراجعة المدقق → التقرير.

3. الاشتراكات والمدفوعات: الشركة تختار خطة → يظهر طلب الدفع للإدارة → الإدارة تراجع الدفع → تؤكد أو ترفض → عند التأكيد يصبح الاشتراك Active، مع منع التفعيل المكرر أو الحالات المتعارضة.

4. اعتماد نطاق الامتثال: الشركة تنفذ Smart Classification → النظام يقترح الأطر → الإدارة تراجع النطاق المقترح → تعتمد الأطر المناسبة → تبدأ رحلة الضوابط والأدلة.

5. مراقبة تقدم الشركة: الإدارة تتابع مستوى الجاهزية، الضوابط المكتملة والناقصة، الأدلة وحالات معالجتها، الفجوات، المخاطر، وخطط المعالجة.

6. إدارة المدققين: طلب تسجيل مدقق → مراجعة بياناته → قبول / رفض / تعليق → تفعيل الحساب → متابعة حالته.

7. تعيين المدقق: اختيار شركة → اختيار مدقق مؤهل → إنشاء Assignment → يصبح بإمكان المدقق رؤية الشركة المعيّنة له فقط → تبدأ المراجعة.

8. متابعة المراجعة: الإدارة تتابع تقدم المدقق، الضوابط التي تمت مراجعتها، الأحكام، طلبات RFI المفتوحة، ردود الشركة، وحالة اكتمال المراجعة، دون أن تحل الإدارة محل الحكم المهني للمدقق.

9. التقارير: متابعة جاهزية الشركة → مراجعة اكتمال البيانات → متابعة حالة مراجعة المدقق → استخراج أو متابعة تقرير الجاهزية، مع التأكيد أنه ليس شهادة امتثال رسمية.

10. CRM والتشغيل: إدارة ملاحظات العملاء، نشاط الشركة، الاشتراكات، الدفع، المدققين، الدعم، وصحة بيانات مكتبة الضوابط.

المخطط الكامل

Admin Login → Operations Dashboard → Company Management → Payment Approval → Compliance Scope Approval → Progress Monitoring → Auditor Management → Auditor Assignment → Review Monitoring → RFI Monitoring → Readiness & Reports → CRM / Support / Platform Monitoring












رحلة الشركة في 1SaudiCyber هي الرحلة الأساسية للمنتج:

زيارة المنصة → التسجيل → التحقق والدخول → اختيار الاشتراك → الدفع → تفعيل الاشتراك → التصنيف الذكي → تحديد واعتماد نطاق الامتثال → تنفيذ الضوابط → رفع الأدلة → تحليل AI الاستشاري → تحليل الفجوات → المخاطر → خطة المعالجة → مراجعة المدقق → الرد على RFI → الأحكام النهائية → تقرير الجاهزية.

بالتسلسل

1. التسجيل والتهيئة: إنشاء حساب الشركة → إدخال بيانات المنشأة → التحقق → تسجيل الدخول → استكمال بيانات الشركة.

2. الاشتراك والدفع: اختيار الخطة → إرسال طلب الدفع → انتظار مراجعة الإدارة → تفعيل الاشتراك.

3. Smart Classification: الإجابة عن أسئلة نشاط الشركة وبيئتها ومتطلباتها → النظام يقترح الأطر المناسبة → انتظار اعتماد النطاق.

4. تنفيذ الامتثال: فتح الإطار → تصفح المجالات والضوابط → معرفة حالة كل ضابط والمتطلبات المطلوبة.

5. الأدلة: فتح الضابط → مشاهدة Evidence Checklist → رفع الأدلة → معالجة الملف → استخراج المحتوى → تحليل AI استشاري → مراجعة النتيجة.

6. الفجوات والمخاطر: معرفة الضوابط المكتملة والناقصة → تحليل الفجوات → تسجيل المخاطر → إنشاء إجراءات المعالجة → تحديد المسؤول والموعد → متابعة التنفيذ.

7. مراجعة المدقق: بعد تعيين المدقق → يراجع الضوابط والأدلة → يصدر حكمًا أو يطلب معلومات إضافية.

8. RFI: تستلم الشركة طلب المعلومات → تفتح الطلب → ترد بنص أو ترفع دليلًا إضافيًا → ترسل الرد → تنتظر مراجعة المدقق → قد يُغلق الطلب أو يعاد فتحه.

9. النتيجة والتقرير: اكتمال المراجعة → ظهور أحكام المدقق → تحديث حالة الجاهزية → إصدار تقرير الجاهزية، مع توضيح أنه ليس شهادة امتثال رسمية أو اعتمادًا حكوميًا.
