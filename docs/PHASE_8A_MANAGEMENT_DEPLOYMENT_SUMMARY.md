# المرحلة 8A — ملخّص إداري لخطة النشر المُحكَم

> العلامة التجارية: **1SaudiCyber — 1saudicyber.com**. (الاسم التقني الداخلي `cybertrust_ksa`.)
>
> **هذه المرحلة خطة فقط وليست تنفيذ نشر.** لم يتم الدخول إلى الخادم، ولم تُجرَ أي هجرات أو تغييرات على
> الإنتاج.

## ما تم إنجازه محليًا
اكتملت محليًا رحلة الامتثال الكاملة: تسجيل الشركة → التصنيف الذكي → قابلية تطبيق الضوابط → رفع الأدلة →
استخراج النص → التحليل الاستشاري بالذكاء الاصطناعي → الحالة النظامية المقترحة (محرك القواعد) →
قرار المدقق النهائي → **تقرير مراجعة امتثال داخلي**. الواجهة عربية أولًا مع دعم الإنجليزية. جميع
الاختبارات الآلية المحلية ناجحة، ومكتبة الضوابط الرسمية تساوي **417** ضابطًا (لا يظهر الرقم القديم 334).

## لماذا نحتاج النشر
نسخة الإنتاج الحالية متأخّرة عن النسخة المحلية (آخر نشر تقريبًا عند `UX-WIZARD-A`). كل ميزات المراحل
6A–7C جاهزة محليًا وغير منشورة بعد.

## ما الذي سيتم نشره
النسخة المحلية المعتمدة **`5771735`** (المرحلة 7C)، وتشمل: التصنيف الذكي، قابلية التطبيق، استخراج النص،
التحليل الاستشاري، محرك القواعد، قرار المدقق، وتقرير المراجعة الداخلي. التغييرات على قاعدة البيانات
**إضافية فقط** (جداول جديدة) ولا تحذف أو تُعدّل بيانات قائمة.

## ما المخاطر
أبرزها: فشل محتمل في الهجرة أو الملفات الثابتة، اختلاف سلوك بوابة الاشتراك مع بيانات الإنتاج، أو توقّف
قصير أثناء إعادة البناء. لكل خطر إجراء وقائي ومُحفّز تراجع موثّق في خطة النشر.

## كيف سنحمي البيانات
قبل أي خطوة: **نسخة احتياطية كاملة لقاعدة البيانات** + نسخة لملفات الوسائط + تسجيل النسخة الحالية
للرجوع إليها. لا تبدأ الهجرة قبل التأكد من نجاح النسخ الاحتياطي.

## كيف نرجع للخلف إذا حدثت مشكلة
إن كانت المشكلة في الكود فقط: الرجوع إلى النسخة السابقة وإبقاء الجداول الإضافية كما هي (غير ضارّة). إن
لزم: استرجاع النسخة الاحتياطية لقاعدة البيانات. توجد محفّزات واضحة للتراجع (فشل الصحّة، أخطاء 500،
تسرّب بيانات بين الشركات، أو ظهور ادّعاء شهادة رسمية).

## ما الذي لن يتم تنفيذه في هذه المرحلة
لا نشر فعلي، لا دخول إلى الخادم، لا هجرات على الإنتاج، لا تغيير أسرار/متغيّرات، لا تغيير Nginx/DNS/SSL،
لا إصدار شهادات أو ادّعاء اعتماد رسمي، ولا أي تكامل دفع أو موصّلات خارجية.

## التوصية
الخطة جاهزة وآمنة. **التنفيذ (المرحلة 8B) يبدأ فقط بعد موافقتك الصريحة وتحديد نافذة زمنية**، ويتطلّب صلاحية
الوصول إلى الخادم. حتى ذلك الحين تبقى نسخة الإنتاج كما هي دون تغيير.
