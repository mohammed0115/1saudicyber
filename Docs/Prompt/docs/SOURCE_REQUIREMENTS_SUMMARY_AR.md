# SOURCE_REQUIREMENTS_SUMMARY_AR

## SRS
- النظام Django 5.x مع PostgreSQL وRedis وCelery وOpenAI وTesseract OCR.
- يدعم NCA ECC + Saudi Aramco SACS-002 + SABIC CyberTrust.
- يدير 334 controls عبر الثلاثة frameworks.
- يدعم Company Registration، Classification، Evidence Upload، AI Analysis، Gap Analysis، Dashboards، Auditor Portal، Monitoring، Reports.

## Prototype v3.2
- يضيف Enterprise Continuous Monitoring.
- يضيف Automated Control Testing كل 15 دقيقة إلى 24 ساعة.
- يضيف Integrations Hub مع 200+ أدوات كمستهدف معماري.
- يضيف Role-Specific Dashboards.
- يضيف Vulnerability Management وPredictive Risk وReal-Time Monitoring.

## Aramco/SACS-002 Report Template
- يعتمد على Third Party Information وAudit Firm Information.
- يصنف الطرف الثالث حسب: Outsourced Infrastructure, Customized Software, Network Connectivity, Critical Data Processor, Cloud Computing Service.
- يحتوي General Requirements وSpecific Requirements.
- يخرج Compliance / Noncompliance count and percentage.

## قاعدة التنفيذ
- لا تدعي أن 200+ integrations حقيقية قبل تنفيذها.
- ابدأ بمشروع Django الحالي.
- أصلح المعمارية أولاً، ثم السيناريوهات.
